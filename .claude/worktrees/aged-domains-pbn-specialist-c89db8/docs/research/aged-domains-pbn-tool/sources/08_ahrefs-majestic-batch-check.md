## Relevance

Both index providers already ship a native bulk/batch workflow — Ahrefs up to 1,000 URLs per batch-analysis run, Majestic up to 400 via web UI or up to 1,000,000 via file upload — meaning a buyer or a builder does **not** need a third-party app just to check a list of candidate domains' backlink metrics in bulk; that part of the job is already a solved, self-serve, paid feature at both major providers. This bears most directly on **H2** (data/cost feasibility) and partially rebuts the "reselling access" escape hatch in the plan's adversarial queries: the raw batch-metrics layer is already commoditized and directly purchasable, so a new product's data-layer differentiation can't be "we'll batch-check backlinks for you" — it would have to be the layers neither provider offers natively: WHOIS history, Wayback/content-history reconstruction, and casino/adult/pharma/hacked-history content classification, none of which appear anywhere on either batch-tool's feature list.
