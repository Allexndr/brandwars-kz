## Relevance

ADVERSARIAL (H2/H4). The exact metrics (Ahrefs DR, Majestic TF/CF) that both the original human-specialist job post and any automated vetting tool would lean on to screen aged domains are shown, empirically, to be cheaply gameable — DR scores of 44-59 bought for $15-85 per domain. This means an automated product built on these same third-party APIs inherits the identical blind spot a human specialist using the same tools would have: neither can reliably distinguish "genuinely authoritative aged domain" from "recently manipulated to look authoritative" using DR/TF alone, which undercuts the core trust proposition of either the freelance job or a software replacement for it.
