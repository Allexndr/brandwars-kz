Majestic explicitly gates all API access behind the top consumer tier (no API on Lite/Pro), which is itself a data point worth treating at face value rather than assuming it's negotiable.

## Verbatim quotes

> "Lite and Pro plans have a 7-day money-back guarantee for new customers."

> "Full API" (listed as the API-tier capability; Lite and Pro tiers show no API access)

Pricing table as published on the page:
- LITE: $49.99/month ($499.99/year) — 1 million Analysis Units, 5,000 Index Item Units, 200,000 API Retrieval Units (no API access)
- PRO: $99.99/month ($999.99/year) — 20 million Analysis Units, 125,000 Index Item Units, 5 million API Retrieval Units (no API access)
- API: $399.99/month ($3,999.90/year) — 100 million Analysis Units, 500,000 Index Item Units, 20 million API Retrieval Units, 5 users, full API access

## Relevance

Majestic's real API tier costs $399.99/month ($3,999.90/year), roughly 4x and 8x the Lite and a step above the Pro consumer tiers respectively — and critically, API access is entirely unavailable below that tier, so there's no cheap "just the API" entry point the way DataForSEO offers. For H2, this sets a concrete floor: a solo builder wanting Majestic's Trust Flow/Citation Flow data programmatically must commit to ~$400/month minimum regardless of actual usage volume, which is a real but not prohibitive cost for a product with a handful of paying customers — the bigger constraint is that this is a fixed subscription, not a pay-per-lookup model, so it only pencils out once the product has enough volume/revenue to justify the fixed commitment.
