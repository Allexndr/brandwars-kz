## Verbatim quotes

> "Google's Penguin algorithm, which now runs in real time as part of the core ranking algorithm, can detect these kinds of schemes."

> "A dead giveaway for many PBNs is having a similar backlink profile. If multiple sites have the same link profile, or if they all link to one website multiple times..."

> "Google can devalue your website rankings as a result. In some cases, you could even wind up with a manual penalty."

> "One such case was the J.C. Penney link scheme that was exposed back in 2011 by The New York Times."

## Relevance

Independent, non-Google confirmation that Google's core ranking algorithm (Penguin, since folded into core ranking) specifically targets PBN-style backlink-profile patterns, with a real-world reference case (J.C. Penney, 2011) showing this kind of manipulation has been publicly exposed and consequential before. Reinforces H3: detection is not hypothetical or merely theoretical policy language — it is an operating algorithmic capability that has been catching real sites for well over a decade, meaning the risk window for a tool built around this tactic has already been closing for a long time, not just recently.
