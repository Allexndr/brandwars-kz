# 45 — Law on Online Platforms and Online Advertising
- URL: https://zakon.uchet.kz/rus/docs/Z2300000018
- Accessed: 2026-08-27
- Source type: primary (statute)
- Credibility (1-5): 5 (Official Kazakh legislation)
- Recency: Law Z2300000018 (2023)
- Bias notes: None

## Verbatim quotes
> "Параметры, используемые в системе рекомендаций онлайн-платформы, должны быть описаны в пользовательском соглашении онлайн-платформы" (Parameters used in recommendation system must be described in user agreement)

## Relevance
Key legal framework for this platform. Requirements: (1) Platform with 100,000+ daily users in Kazakhstan must appoint legal representative. (2) User agreement must describe recommendation system parameters. (3) Platform must enable users to receive content without profiling. (4) Parameters and logic must be transparent to users. This directly applies to ranking/recommendation mechanism if >100K daily users.
