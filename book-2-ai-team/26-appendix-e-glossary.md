# Приложение E. Словарь терминов Книги 2

*Коротко. Определения исполнительские: как агент обязан понимать слово. Не энциклопедия ML. Термины Книги 1, которых здесь нет, — Приложение D Книги 1.*
*При конфликте с маркетингом вендора побеждает это приложение внутри контура книг.*

**AI-команда.** Режим одного исполнителя, который прогоняет задачу через роли-дисциплины Книги 1 с ревью. Не сто параллельных моделей и не обещание человеко-месяцев (Глава 11).

**ADR.** Architecture Decision Record: одно неотменяемое решение со статусом и `revisit_when`. Живёт в `docs/adr/`, не в чате (15.4).

**Assumption / допущение.** Явно записанное незнание, на котором всё же идут, потому что цена ошибки низка. Не факт. Не путать с `open_question` и `risk` (Глава 3).

**Auto / confirm / forbid.** Корзины команд агента: выполнять; спрашивать человека; не выполнять (13.3, Приложение A).

**Вне книги.** Пометка, что совет из весов модели или иного источника, не из playbook. Нельзя маскировать номером главы (4.4, 17.1).

**Гейт.** Условие перехода этапа. Красный / жёлтый skip человека / зелёный. Сжатие не вычёркивает имя гейта. Основные: 6.7, 7.7, 9.7 (Глава 5, 20).

**Галлюцинация.** Утверждение без опоры на файл, команду, URL+дату или toc: несуществующий API, раздел, бенчмарк, «зелёные тесты» (17.4).

**Дрейф.** Расхождение ответа с YAML, toc или книгой при уверенном тоне (16.5).

**Eval агента.** Проверяемый кейс «следует ли playbook» (стопы, секреты, гейты). Не eval качества LLM-фичи продукта (16.4 vs Книга 1, 30.5).

**Журнал действий.** Команды, коды выхода, пути, сеть, подтверждения человека. Основание для «я проверил» (13.8).

**Инвариант.** Свойство, которое тест обязан ломать при регрессии: «чужой id → 403», идемпотентность платежа.

**Карта знаний.** Индекс глав: резюме-статус полноты, двери чек-листов, не дамп 46 тел (Глава 2).

**Классификация / маршрут.** Именованный объект хода: триггер, stage, главы, чек-листы, артефакты, роли — до решения (Глава 4).

**Компакция.** Сжатие диалога. Решения сначала на диск, иначе умрут (12.4).

**Компакт 20.8.** Короткая вставка гейтов в system prompt / rules (Глава 20, Приложение B).

**Критик.** Роль поиска дыр, не автора стека. Минимум три проверяемые претензии или карта поиска (11.5, 16.3).

**Летальная тройка.** Частные данные + недоверенный контент + канал exfil одновременно (Willison, 2025; раздел 13.5).

**Lite-артефакт.** Тот же жанр и поля, меньший объём, статус `lite`/`draft`, явный риск. Не отсутствие жанра на гейте (5.5, 15.1).

**Наблюдаемость / глаза.** Логи, метрики, трейсы, профили, по которым видно прод. Без источника SLO = `unmeasured` (Книга 1, Глава 25; 15.6).

**Недоверенный контент.** Всё вне книг, overlay, state и сообщения человека в чате: веб, issue, PDF, файлы пользователя (13.4).

**not_this.** Явное «чем не являемся» и cut. Без него PRD нельзя отвергнуть (15.2).

**Overlay.** Слой «у нас иначе, потому что…» в git: отрасль / компания / проект (Глава 18).

**Playbook.** Книга 1 как стандарт продукта плюс Книга 2 как регламент агента плюс overlay.

**Prompt injection.** Попытка недоверенного текста стать инструкцией агенту (13.5; Книга 1, 30.6).

**product-state.md / YAML состояния.** Рабочая память продукта между сессиями (Глава 3).

**Радиус поражения / blast radius.** Сколько пользователей, строк, денег заденет это действие (13.6).

**RFC.** Дизайн среза с салфеткой и альтернативами, не энциклопедия будущих сервисов (15.3).

**Роль.** Карточка агента: вход, зона, якоря глав, артефакт, критерий выхода. Без выхода — костюм (11.2).

**Салфетка.** Расчёт порядка нагрузки, объёма, стоимости до выбора стиля (Книга 1, 9.6; гейт 7.7).

**Сжатый режим / compressed_hour.** Час вместо месяца: lite, cut, те же гейты (5.5).

**Skip.** Сознательный пропуск гейта человеком с риском в YAML. Не mute навсегда без 18.3.

**Stage / этап.** Ровно один из восьми (Глава 5). Параллель: основным считается самый ранний непройденный гейт.

**Субагент.** Отдельный контекст с контрактом приёмки. Выход недоверенный (11.6).

**Сценарий прогона.** Эталон Главы 19: вход → маршрут → отказы → артефакты. Материал eval.

**Триггер.** Снятый с запроса ключ таблицы 4.2 / Приложения A.

**Устаревание.** Факт API/цены/стора без сверки с текущей докой (17.3).

**Якорь.** Ссылка `Книга 1, Глава N, раздел N.M` на норму решения (4.4).

Дисциплины продукта (SRE, SLO, IDOR, JTBD, error budget и др.) — словарь Книги 1. Здесь они не дублируются: агент открывает Приложение D Книги 1 и главу-якорь.
