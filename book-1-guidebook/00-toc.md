# Книга 1. Продукт мирового уровня

## Инженерно-продуктовый playbook: от идеи до системы, которой пользуются миллионы

**Оглавление**

Целевой объём: 250–350+ условных страниц (условная страница = 2500 символов).
Каждая глава: обзор → механика по разделам → чек-листы → фреймворки → примеры → антипаттерны → перекрёстные ссылки.
